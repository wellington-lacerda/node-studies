# 🚀 Node Studies

Repositório dedicado ao estudo, prática e documentação de conceitos fundamentais e avançados de **Node.js**.

## 📌 Sobre o Projeto

Este projeto reúne exercícios, pequenos projetos e anotações sobre o ecossistema Node.js. O objetivo é consolidar conhecimentos desde a base até o desenvolvimento de APIs completas.

---

## 🛠️ Tecnologias Utilizadas

- **Runtime:** [Node.js](https://nodejs.org/)
- **Linguagem:** JavaScript (ES6+) / TypeScript
- **Gerenciador de Pacotes:** npm ou yarn
- **Frameworks & Bibliotecas Principais:**
  - Express / Fastify
  - Prisma / TypeORM / Mongoose
  - dotenv
  - nodemon / tsx
